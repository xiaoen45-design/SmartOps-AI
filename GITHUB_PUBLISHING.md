# GitHub Publishing Checklist

Recommended repository name: `smartops-ai`

Recommended GitHub description:

> Award-winning AI-assisted hotel maintenance system integrating Business Analytics, SQL/MySQL dashboards, HITL review and technician workflow.

Before making the repository public:

- Add 3-4 selected screenshots to `docs/screenshots/` and embed them in `README.md`.
- Add your live Netlify demo link near the top of `README.md` only after the demo matches the project flow you want recruiters to see.
- Pin this repository first on your GitHub profile.
- Do not commit `config/local.php` or `smartops_fastapi/.env`.
- Check `git status` before every push for unexpected credentials or local files.
- Keep group-work attribution accurate: the repository focuses on the web/business-analytics implementation and describes RAG-LLM/HITL only at integration boundaries.
